# Product

## Register

product

## Platform

web

## Users

主要用户是使用 Kimi Code 进行日常开发的个人开发者。他们在本地项目中管理多个 Workspace 和 Session，查看 Agent 输出，并执行文件、终端、浏览器与审批操作。

## Product Purpose

Moon Code 提供一个以 Kimi Code 为唯一 Agent 内核的本地开发工作台，把会话、Transcript、文件、终端、浏览器、审批、用量和桌宠状态整合到一个可持续工作的桌面界面中。成功意味着开发者无需离开项目上下文，就能完成从提示、审阅到执行验证的完整闭环。

## Positioning

Moon Code 是一个 Kimi Code 原生的本地开发工作台，让开发者在同一项目上下文中完成 Agent 协作、代码验证与运行状态管理。

## Brand Personality

界面应保持高效、清晰、可靠。当前首页是视觉与交互基准；产品表达应优先帮助用户快速理解状态、做出下一步操作，并对运行结果保持可信。

## Anti-references

避免游戏化过度、营销落地页化，以及信息堆叠但缺少层级的视觉方向。

## Design Principles

- 保持项目上下文连续，让会话、文件、终端和预览围绕同一工作流协同。
- 让运行状态和下一步行动清晰可见，减少用户在复杂 Agent 流程中的判断成本。
- 以官方 Kimi 数据和状态为事实来源，界面反馈应准确、可追溯、不过度承诺。
- 用克制而高效的桌面工具语言承载复杂能力，避免装饰抢过工作内容。

## Accessibility & Inclusion

以 WCAG 2.2 AA 为整体目标，优先保证文字与背景的对比度、清晰的焦点和状态表达，并尊重 `prefers-reduced-motion`。键盘操作不是当前阶段的重点验收项；后续如扩大使用人群，再单独补齐键盘路径审计。
