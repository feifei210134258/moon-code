# Moon Code 0.2.3 发布说明

Moon Code 0.2.3 聚焦任务反馈、思考选择、Git 空状态与整体可读性，使桌面工作台在等待回复和非 Git 工作区中表达更准确。

## 任务与思考体验

- Assistant 已接收任务但尚未返回首段内容时，显示“Kimi 已接收任务，正在生成回复…”及等待动效，不再只出现头像。
- 移除不存在的“关闭思考”界面选项，新任务继承用户最近一次有效的思考强度选择。
- 新任务模型默认值保持为有效模型，不再回落到无效的关闭状态。

## Git 状态

- 工作区没有未提交更改时显示中性空状态。
- 当前目录不是 Git 仓库时显示普通提示，不再把 Kimi `FS_GIT_UNAVAILABLE` 当成用户错误。
- 网络、权限和未知协议失败仍保留真实错误反馈。

## 字体与可读性

- 会话正文和输入框调整为 16px，导航及高频控件调整为 14px，代码与终端调整为 13px。
- 将零散字号收敛为固定的 `rem` 语义尺度，并同步更新标题、说明文字和桌宠提示。
- 通过 1440px、1024px 与 760px 窗口渲染检查，未发现字号放大引起的意外截断。

## 验证

- `pnpm check` 通过：399 项自动化测试通过、6 项显式 opt-in 测试跳过，类型检查和生产构建成功。
- 字体设计系统扫描无遗留项。
- macOS 产物仍为未签名 arm64 DMG；首次打开方式与限制见[最小运行与未签名分发](./08-minimum-run-and-distribution.md)。
