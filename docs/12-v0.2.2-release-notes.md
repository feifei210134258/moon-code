# Moon Code 0.2.2 发布说明

Moon Code 0.2.2 修复 0.2.1 中“没有模型元数据的 Provider 无法编辑”的问题，并补上真实 DeepSeek Runtime 链路验证。

## Provider 修复

- 编辑零模型 Provider 时，不再在请求前直接报错。
- 已知服务会通过 Kimi 官方模型目录补全 PUT 所需的模型别名和上下文大小；DeepSeek 可根据连接名称或 `api.deepseek.com` 自动识别。
- 私有或未知 OpenAI 兼容服务可填写首个模型别名和上下文 Token，生成符合 Kimi 0.29.2 契约的模型元数据。
- Provider 与模型别名在写入前会移除已有的 `provider/` 前缀，避免重命名时产生重复前缀。
- 新增 Provider 在 Runtime 支持管理路由时改用官方 `POST /api/v1/providers`，与编辑路径保持一致。
- 编辑时保留未修改的 Base URL；API Key 留空仍由 Kimi 官方 PUT 语义保留已有凭据。

## 验证

- 使用隔离的 Kimi 0.29.2 Runtime，将零模型 `pixel` Provider 编辑并重命名为 DeepSeek，成功自动补全模型目录。
- 使用真实 DeepSeek 凭据在 Kimi Session 中完成模型调用，并获得预期回复；测试后已清空隔离 Runtime 中的临时凭据。
- `pnpm check` 通过：392 项自动化测试通过、6 项显式 opt-in 测试跳过，类型检查和生产构建成功。
- macOS 产物仍为未签名 DMG；首次打开方式与限制见[最小运行与未签名分发](./08-minimum-run-and-distribution.md)。
