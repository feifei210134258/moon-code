# Moon Code 0.2.6 发布说明

Moon Code 0.2.6 修复 Kimi 任务结束事件未完整同步时，主会话和桌宠持续显示进行中的问题。

## 任务状态

- 兼容 `prompt.completed`、`prompt.aborted`、`turn.ended` 和终态 `session.status_changed`。
- 即使服务端未发送 `event.session.work_changed`，也会正确结束 Composer 的 loading/pending 状态。
- 任务结束后清除活动 Prompt，避免停止按钮和任务进行态残留。

## 桌宠

- 桌宠同步主 Turn 的开始与结束事件。
- 任务完成后进入完成动画，不再持续显示进行态。

## 验证

- `pnpm check` 全部通过。
- macOS 产物为未签名 arm64 DMG；首次打开方式与限制见[最小运行与未签名分发](./08-minimum-run-and-distribution.md)。
