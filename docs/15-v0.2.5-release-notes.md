# Moon Code 0.2.5 发布说明

Moon Code 0.2.5 修复 Kimi 套餐用量兼容问题，并改善停止任务后的 Prompt 恢复与 Skill 编辑体验。

## 套餐用量

- 兼容 Kimi 0.30 的 `name`、`window`、`reset_at` 用量结构。
- 保持对 Kimi 0.29 `label`、`reset_hint` 结构的兼容。
- 根据语义窗口生成稳定名称，并本地化绝对重置时间。

## Prompt 恢复

- 用户停止尚未生成回复的任务后，可直接从最后一条用户消息选择“撤回并编辑”。
- 撤回继续使用 Kimi 官方 Session Undo，并将文字与附件恢复到 Composer。

## Skill 编辑

- 从技能列表选择 Skill 后，在 Composer 内显示蓝色技能令牌。
- Skill 名称转为易读形式，参数继续在同一输入区编辑。
- 支持点击技能令牌或在行首按 Backspace 移除，同时保持 `/skill args` 提交协议。

## 验证

- `pnpm check`、生产构建与相关 Renderer/Main/Kimi Adapter 测试通过。
- macOS 产物仍为未签名 arm64 DMG；首次打开方式与限制见[最小运行与未签名分发](./08-minimum-run-and-distribution.md)。
