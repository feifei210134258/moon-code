# Moon Code 0.2.4 发布说明

Moon Code 0.2.4 微调会话排版，使消息阅读和任务输入保持一致的视觉密度。

## 字体调整

- 会话消息正文由 16px 调整为 15px。
- Composer 输入框同步调整为 15px。
- 导航、设置、右栏、代码、终端与标题字号保持不变。
- 新增独立的 Conversation 字号 token，避免影响其他正文和控件。

## 验证

- 会话与 Composer 针对性测试通过。
- 字体设计系统扫描无遗留项。
- `pnpm check`、生产构建和打包态冒烟测试通过。
- macOS 产物仍为未签名 arm64 DMG；首次打开方式与限制见[最小运行与未签名分发](./08-minimum-run-and-distribution.md)。
